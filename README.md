# The Robot Vacuum's Funniest Excuse

A make.fun entry for [The Robot Vacuum's Funniest Excuse](https://make.fun/competitions/u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2): one line, at most 120 characters, in which a robot vacuum explains why it missed a spot.

The entry line (71 characters):

> My cliff sensor saw the edge of the rug and decided I was about to die.

`main.py` (Python 3.13, standard library only) picks the line from an eight-candidate tournament scored on specificity, surprise and freshness, then writes it to `/output/entry.txt`. Run `python3 main.py --tournament` to see the table, `--check` to gate-check the line, `--self-test` to confirm byte-identical output.
